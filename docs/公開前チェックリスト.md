# 公開前チェックリスト

このチェックリストは、現在の目的である「GitHubリポジトリをPublicにする」「Apple Developer Programなしで、署名なしDMGを試験配布する」ためのものです。

App Store配布や、一般ユーザー向けの署名済み配布は対象外です。必要になった時点で「一般配布へ進むとき」を確認します。

## Public化の直前

- [ ] 全ブランチ、タグ、コミット履歴が公開されても問題ない
- [ ] GitHubのIssue、Pull Request、Release、Actionsログ、Wiki、Projectsに非公開情報がない
- [ ] `git status`がcleanである
- [ ] APIキー、秘密鍵、証明書、`.env`、DMG、アプリ本体、sidecar、モデルがGitに含まれていない
- [ ] `LICENSE`、`SECURITY.md`、[プライバシーとデータ取り扱い](./プライバシー.md)、[使い方](./使い方.md)の内容とリンクを確認する
- [ ] `main`と`develop`の役割、および公開後のデフォルトブランチを決める

## ソースを公開する場合

- [ ] `bun install --frozen-lockfile`が成功する
- [ ] `bun run lint`が成功する
- [ ] Tauriの生成物とダウンロードしたsidecarが追跡対象になっていない

## DMGを試験配布する場合

- [ ] Apple Silicon Macで`bunx tauri build --bundles dmg`が成功する
- [ ] 対応環境（Apple Silicon、Apple標準モデルはmacOS 26以降）をREADMEとRelease本文に記載する
- [ ] Release本文に「未署名のため初回起動時にmacOSの確認が必要」と記載する
- [ ] GitHub ReleaseをPublishし、ActionsがDMGを添付したことを確認する
- [ ] 別のApple Silicon MacでDMGのダウンロード、起動、主要フローを確認する
- [ ] リポジトリとReleaseをPublicにした状態で「更新を確認」が最新版を取得できる

## 今回は不要なもの

- Apple Developer Programへの登録
- Developer ID証明書、notarization用のSecret
- Personal Access Token（Release添付はWorkflowの`GITHUB_TOKEN`を使用）
- Tauri Updaterの導入

## 一般配布へ進むとき

不特定多数へ継続的に配布する段階で、次を追加で確認します。

- Developer ID署名とnotarization
- DMGまたはアプリから確認できる第三者ライセンスのNOTICE
- sidecarとAIモデルの利用条件、配布条件、取得元
- サポート窓口と、実際のユーザー入力を使ったデータ送信の確認

未署名DMGの起動方法は[リリース手順](./リリース手順.md)に記載しています。
