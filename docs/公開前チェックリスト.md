# 公開前チェックリスト

## このリポジトリの確認結果

2026-09-04時点で、ローカルの現在のHEADと参照可能なGit履歴を確認しました。

- [x] 典型的なAPIキー、秘密鍵、証明書のパターンは検出されていない
- [x] `.env`、`.pem`、`.p12`、DMG、アプリ本体はGitの追跡対象にない
- [x] Gitのコミット作成者はGitHub noreplyアドレスのみ
- [x] Actionsの`GITHUB_TOKEN`はWorkflowのSecret参照だけで、値はコードにない
- [x] 外部sidecarはGitに含めず、ビルド時に取得している
- [ ] 外部バイナリとAIモデルのライセンス・NOTICEを確認する
- [ ] GitHub上のRelease、Actionsログ、Issue、Wiki、Projectsを確認する

上記の自動的な確認は、すべての秘密情報を保証するものではありません。公開直前には、作業者自身でも差分、履歴、GitHub画面を確認してください。

## 公開前にローカルで行うこと

- [ ] `git status`で意図しない変更がない
- [ ] `bun install --frozen-lockfile`が成功する
- [ ] `bun run build`が成功する
- [ ] `bun run lint`が成功する
- [ ] macOS Apple SiliconでDMGを起動できる
- [ ] APIキー、署名鍵、notarization情報をコードやREADMEに書いていない
- [ ] サンプル文章に実在人物、社内情報、未公開資料が残っていない
- [ ] `LICENSE`とこの文書の内容を確認する

## GitHub画面で確認すること

- [ ] Releasesの説明、添付ファイル、古いテスト用Assetを確認する
- [ ] Actionsの過去ログに秘密情報や個人情報が出ていない
- [ ] Issue、Pull Request、Wiki、Projectsに非公開情報がない
- [ ] Deploy keys、Webhooks、Actions Secretsの用途を確認する
- [ ] `main`への直接pushを禁止し、必要なブランチ保護を設定する
- [ ] Actionsの外部Actionを許可する設定と権限を確認する
- [ ] Secret scanningとPush protectionを有効にする
- [ ] リポジトリをPublicへ変更する

リポジトリの公開変更後は、ソースだけでなく、IssueやReleaseなどの公開範囲も再確認してください。

## Releaseと更新確認

- [ ] リリース対象の変更を`main`へ反映する
- [ ] `src-tauri/tauri.conf.json`と`src-tauri/Cargo.toml`のバージョンを揃える
- [ ] GitHubのRelease画面で対応するタグを作成する
- [ ] ReleaseをPublishする
- [ ] GitHub ActionsがDMGをReleaseへ添付したことを確認する
- [ ] 未署名配布の場合のmacOS警告をREADMEとReleaseノートに記載する
- [ ] アプリ内の「更新を確認」がHTTP 404にならず、最新Releaseを取得できる

更新確認はGitHub Releases APIを認証なしで利用するため、リポジトリとReleaseがPublicである必要があります。非公開リポジトリではHTTP 404になることがあります。
