# プライバシーとデータ取り扱い

この文書は、現在のアプリ実装におけるデータの保存先と外部送信先を説明します。サービスの仕様変更時には、この文書も更新してください。

## ローカルに保存されるデータ

- プロジェクト、動画から作成した中間データ、文字起こし、OCR結果、生成記事はmacOSのアプリローカルデータ領域に保存されます。
- ダウンロードしたローカルAIモデルもアプリローカルデータ領域に保存されます。
- OpenAI APIキーはmacOS Keychainに保存されます。アプリのプロジェクトファイルには保存しません。

## 外部へ接続する処理

### GitHub

アプリ内の「更新を確認」は、最新版のReleaseを確認するためにGitHub Releases APIへ接続します。更新がある場合、ダウンロードボタンからGitHub Releaseページをブラウザで開きます。

### Hugging Face

ローカルモデルを初めて利用するとき、モデルファイルをHugging Faceからダウンロードします。動画やプロジェクトの内容をモデル配布元へ送信する処理ではありません。

### YouTube URL import

YouTube URL importを選択した場合、入力したURLは動画情報の確認と、ユーザーが明示的に開始した動画取得のためにYouTubeへ接続されます。取得した動画は、プロジェクトごとのアプリローカルデータ領域へ保存されます。アプリが動画を中継サーバーへ送信することはありません。

ブラウザCookieやログイン情報は自動取得しません。公開済みの単一動画のみを対象とします。動画の保存・解析に必要な権利や許諾は、利用者の責任で確認してください。

### OpenAI

OpenAIの機能を選択した場合、入力したAPIキーを使ってOpenAI APIへ接続します。処理内容に応じて、次のデータが送信されます。

- 文字起こし：音声ファイル
- OpenAI OCR：スライド画像とOCR指示
- OpenAI本文生成：文字起こし、OCR結果、本文生成用の指示

OpenAI側のデータ保持、利用、削除については、OpenAIの利用規約・プライバシーポリシー・APIの最新仕様が適用されます。機密情報や第三者の個人情報を処理する場合は、所属組織の規程と各サービスの条件を確認してください。

## 利用者の責任

動画、音声、画像、講義資料に含まれる著作権・肖像権・個人情報などについて、利用者が必要な権利と許諾を確認してください。

ローカルモデルを選択した場合でも、モデルのダウンロード時には外部ネットワークへ接続します。外部通信を許可できない環境では、ローカルモデルの初回ダウンロードを行わないでください。
